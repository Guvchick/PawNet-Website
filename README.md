# PawNet-Website

Статический сайт PawNet на Cloudflare Workers (static assets, без серверного кода).

Страницы собраны из SVG-экспорта Figma: один фрейм 1440px на страницу.

## Структура

```
public/              — то, что деплоится
├── index.html       — Landing          → /
├── ip.html          — IP              → /ip
├── faq.html         — FAQ             → /faq
├── offer.html       — Оферта           → /offer
├── privacy.html     — Политика         → /privacy
├── 404.html         — страница ошибки
├── css/page.css     — вписывает фрейм 1440px во вьюпорт
├── favicon.svg
├── robots.txt
├── sitemap.xml
└── _headers         — кэш и security-заголовки

docs/source/figma-export.html   — исходный экспорт из Figma (все 5 фреймов в одном файле)
wrangler.toml                   — конфиг Workers
```

## Разработка

```sh
npm install
npm run dev      # локальный сервер на http://localhost:8787
```

## Деплой

```sh
npm run check    # проверка конфига без публикации
npm run deploy   # публикация
```

Домен `pawnet.ink` привязывается в дашборде Cloudflare (Workers → Settings → Domains & Routes)
или через `routes` в `wrangler.toml`.

## Что нужно знать про эти страницы

Весь текст в экспорте — векторные контуры (`<path>`), а не текст:

- его нельзя выделить, скопировать или найти поиском по странице;
- поисковики и скринридеры его не видят — SEO и доступности нет;
- страницы очень тяжёлые (замерено brotli -q9, примерно так сожмёт и Cloudflare):

  | страница | на диске | по сети |
  |---|---|---|
  | `index.html` | 1.33 МБ | ~0.45 МБ |
  | `ip.html` | 0.49 МБ | ~0.16 МБ |
  | `faq.html` | 3.88 МБ | ~1.18 МБ |
  | `offer.html` | 17.70 МБ | ~5.08 МБ |
  | `privacy.html` | 11.25 МБ | ~3.28 МБ |

  То есть `offer` — это 5 МБ трафика и 17.7 МБ разметки на парсинг у клиента;
  на слабом телефоне страница будет заметно тормозить. Лимит Cloudflare на один
  файл ассетов — 25 МиБ, в него укладываемся, но запаса немного;
- вёрстка не адаптивная: фрейм масштабируется целиком, на телефоне текст мелкий.

Это нормально как быстрый деплой макета. Для рабочего сайта страницы нужно
пересобрать реальной вёрсткой — начать стоит с `offer` и `privacy`, они самые тяжёлые
и состоят почти целиком из текста.
