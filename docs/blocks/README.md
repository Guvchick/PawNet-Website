# docs/blocks/

Сюда кидай блоки из Figma — **файлами, не сообщением в чат**: паста обрезается
на 50 000 символах, и конец блока теряется.

Как забрать из Figma: выделить фрейм или секцию → правой кнопкой →
**Copy/Paste as → Copy as code** → сохранить в файл сюда.

## Что нужно сейчас

| Файл | Что в нём | Зачем |
|---|---|---|
| `faq.html` | страница «Ответы на вопросы» целиком | 27 вопросов в 6 категориях — переписывать с картинки на глаз долго и с опечатками |
| `offer.html` | Публичная оферта целиком | юридический текст, нужен дословно |
| `privacy.html` | Политика конфиденциальности целиком | то же |

Важно: нужен именно **copy as code**, а не SVG-экспорт. В SVG-экспорте текст
превращается в векторные контуры, и прочитать его нельзя — из-за этого и
пересобираем сайт.
